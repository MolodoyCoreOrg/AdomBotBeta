# 🤖 AdomBot (Beta) — Telegram Bot in Python

Этот репозиторий представляет собой исходный код бота **AdomBot (Beta)**, объединяющего две ключевые идеи:
1. **Инлайн-режим «пересчет пидаразов»** (счетчик пидораз-метра, выявление пидора дня, общая игровая статистика).
2. **AI-модерация на антипропаганду наркотиков**: автоанализ случайных сообщений участников, вырезание подозрительного слова и генерация уморительного псевдонаучного обвинения с предложением выписать мут.

## 🛠 Установка зависимостей

Бот разработан на современном Python 3.10+ с использованием передовых асинхронных библиотек:
- **aiogram** (v3.x) — мощная асинхронная библиотека для Telegram Bot API.
- **google-genai** (v2.x) — официальный современный SDK от Google для связи с моделями семейства Gemini.

Для установки всех необходимых библиотек выполните команду:
```bash
pip install aiogram google-genai
```

## ⚙️ Настройка переменных окружения

Бот считывает ключи безопасности напрямую из переменных окружения. Настройте следующие переменные в вашей системе или добавьте их в `.env` файл перед стартом:

```bash

export TELEGRAM_BOT_TOKEN="ВАШ_TELEGRAM_БОТ_ТОКЕН"

# Ключ Gemini API для генерации забавных объяснений наркопропаганды
export GEMINI_API_KEY="AQ.Ab8RN6IHA6WQVyTJtjqtfp6dh8cvhlx4gwN3OQhmUVsLXgUFeg"
```

## 🚀 Запуск бота

Чтобы запустить асинхронного бота в режиме лонг-поллинга (опроса серверов Telegram), выполните команду:
```bash
python main.py
```

## 📂 Структура файлов

- `main.py` — Главная точка входа. Настраивает роутеры и хэндлеры `aiogram`, обрабатывает инлайн-запросы `@AdomBot_bot`, запускает интерактивную лотерею пидора дня и настраивает коллбэки для мутов.
- `ai_checker.py` — Модуль интеграции с Gemini API. Отвечает за структурированную генерацию причин для заглушения с использованием схемы JSON `ResponseSchema`. Имеет умный оффлайн-режим с пресетами для бесперебойной работы при отсутствии сети или ключа.
- `README.md` — Данное руководство.

## 💻 Возможности и команды бота

### 1. Инлайн-режим: `@AdomBot_bot`
Напишите юзернейм вашего бота в поле ввода сообщений в любом чате:
* **📈 Твой Пидор-Метр**: Рассчитывает процент пидораста на сегодня. Результат закреплен за ID пользователя на 24 часа!
* **👑 Выявить Пидора Дня**: Публикует интерактивный радар, который после клика на кнопку анализирует участников и выявляет Пидора Дня.
* **📊 Топ-Статистика**: Показывает рейтинговую таблицу постоянных активистов чата.

### 2. Защита от пропаганды наркотиков
* **Автоматически**: Бот имеет 5% шанс зацепиться за любое случайное сообщение, либо срабатывает со Стопроцентным шансом при упоминании подозрительного сленга (`клаут`, `соли`, `флекс`, `газ`). Он придумывает карикатурное обоснование, почему это слово пропагандирует наркотик, и выводит кнопку "Применить мут".
* **По команде**: Ответьте на чьё-то сообщение в чате командой `/check_drugs`. Бот превентивно запустит моментальную лингвистическую экспертизу.
