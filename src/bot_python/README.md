# 🏳️‍🌈 Пересчет Пидаразов — Telegram Bot Extension (Python)

Данный модуль добавляет в вашего существующего Telegram-бота интерактивный пожизненный выбор номеров (1-100), утренний пересчет со сбором утренней явки и поддержку удобного инлайн-режима во всех сторонних чатах.

## 📁 Структура файлов проекта
В папке находятся следующие файлы:
1. `storage.py` — Класс `JSONRecountStorage`. Берет на себя хранение зарегистрированных пидаразов, занятых номеров и истории утренних отметок в файле `recount_data.json`.
2. `bot_telebot.py` — Готовый код расширения на базе **pyTelegramBotAPI (telebot)**.
3. `bot_aiogram.py` — Готовый асинхронный код расширения на базе **Aiogram v3**.

---

## 🛠️ Как интегрировать в существующего бота

### Шаг 1: Установка зависимостей
Выберите одну библиотеку, под которой работает ваш основной бот:

```bash
# Для pyTelegramBotAPI (Telebot)
pip install pyTelegramBotAPI

# Для асинхронного Aiogram v3
pip install aiogram
```

### Шаг 2: Настройка окружения (`.env`)
Убедитесь, что у вас прописана переменная окружения с токеном вашего бота, полученным от `@BotFather`:

```env
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
```

### Шаг 3: Включение Inline-режима (ОБЯЗАТЕЛЬНО)
Чтобы пользователи могли вызывать бота в любых чатах через `@имя_бота`:
1. Зайдите в Telegram в бота `@BotFather`.
2. Отправьте команду `/setinline`.
3. Выберите вашего бота из списка.
4. Задайте плейсхолдер (например: `Введите число...` или `Пересчет пидаразов`).

## 🚀 Как работает функционал:

### 1. Выбор номера
Каждый зашедший в бот пользователь может отправить обычное текстовое сообщение с любым числом в диапазоне от **1 до 100**. 
- Бот проверит локальную БД. Если этот слот свободен и у пользователя еще нет присвоенной роли — слот резервируется за ним навсегда. 
- Изменить свой пожизненный номер нельзя. Занятый кем-то номер повторно выбрать невозможно.

### 2. Список занятых слотов
Команда `/list` (или кнопка на старте) выводит полный список всех занятых слотов с кликабельными гиперссылками на профиль пользователя:
- Если у пользователя есть публичный `@username`, линкуется его юзернейм.
- Если юзернейма нет, выводится скрытый `tg://user?id=...` для перехода прямо на диалог.

### 3. Инлайн-режим через @
Пользователи могут вписать `@имя_вашего_бота` в поле ввода текста в абсолютно любом стороннем чате:
- Если у пользователя ранее **выбран** номер (например, 7): бот предложит красивый инлайн-вариант: *"Пидараз 7 на связи"*, который моментально запостит в групповой чат стилизованное сообщение с ссылкой на человека.
- Если номер еще **не выбран**: бот отобразит подсказку *"Я безномерный пидараз 🤷‍♂️"* и покажет кнопку *"Выбрать номер"*, ведущую в личные сообщения с ботом для завершения регистрации.

### 4. Утренний пересчет
Для теста запущена команда `/morning_recount_admin`. Вы можете поставить вызов метода `trigger_morning_recount()` на таймер (`apscheduler`, `celery` или системный `cron` скрипт), чтобы каждое утро в 9:00 рассылать всем зарегистрированным лицам интерактивную кнопку: *"⏰ ПЕРЕСЧЕТ ПИДАРАЗОВ! Пидараз 7 на связи???"*.
- После клика по кнопке бот фиксирует явку на текущую дату и шлет глобальный оповещающий анонс по всей базе: *"📣 Пересчет: Пидараз 7 (@username) на связи!"*.
