## Формат имен файлов:
- `birthday_1.jpg` - для ниga204vip (Адамчик)
- `birthday_2.jpg` - для @раzгон (Вадим)
- `birthday_3.jpg` - для TONI STARK (Костян 444)
- ... и так далее до `birthday_57.jpg`

## Поддерживаемые форматы:
- JPG/JPEG
- PNG
- GIF (анимированные)

## Рекомендации:
- Размер изображения: до 5MB
- Рекомендуемое разрешение: 800x600 или квадратное 1:1
- Можно использовать тематические GIF с праздничной атрибутикой
